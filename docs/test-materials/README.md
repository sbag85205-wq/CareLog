# OCR 인식·약 종류 분류 정확도 확인 자료

자동 테스트는 가상 글자로 규칙을 검증합니다. 실제 사진의 인식률과 분류 정확도는 사람이 직접 찍어서 확인해야 합니다. 이 폴더는 그 확인용 양식입니다.

## 자동으로 확인되는 것 (가상 데이터)

| 대상 | 테스트 |
| --- | --- |
| 상자·영수증 글자 → 제품명 후보 (잡음, 수량, 금액 표기 변형) | `src/lib/prescription/product-text.test.ts` |
| 처방전 글자 → 약 줄·처방일·진료과 | `src/lib/prescription/parse.test.ts` |
| 약효 분류 번호·성분 → 사용자용 종류, 근거 없으면 미분류 | `src/lib/rx/feelpill.test.ts` |
| 메모 → 태그 제안 (불편/도움/이유/예전 복용 구분) | `src/lib/rx/feelpill.test.ts` |

## 사람이 확인할 것 (실제 사진 — 로그인 버전, 본인 소유 약만)

1. 로그인 버전에서 약 등록하기 → 일반약 상자 / 약국 영수증 / 처방전 순서로 찍습니다.
2. 결과를 [`ocr-classification-check.csv`](ocr-classification-check.csv)에 한 줄씩 적습니다. 사진 파일은 저장소에 올리지 마세요.
3. 아래 값을 계산합니다.
   - 제품명 인식률 = `OCR 첫 후보 정답` 수 ÷ 전체
   - 후보 적중률 = `식약처 후보 안에 정답` 수 ÷ 전체
   - 분류 정확도 = `자동 분류 정답` 수 ÷ (`미분류`가 아닌 수)
   - 미분류 비율 = `미분류` 수 ÷ 전체

주의할 점:

- 이름, 생년월일, 처방전 전체 사진, 영수증 금액은 기록하지 않습니다.
- 앱은 사진을 서버로 보내지 않습니다. 식약처에는 제품명만 보냅니다.
- 분류가 틀린 경우 `자동 분류 근거` 칸에 약효 분류 번호를 적어 두세요. 나중에 `categories.ts`의 대응표를 보완하는 데 씁니다.
